# Anti-Gravity Portfolio Website

A minimalist, deep dark-themed portfolio website for a Data Analyst, featuring "Anti-gravity" design elements and neon glow effects.

## Features
- **Cyber-Dashboard Aesthetic**: Deep navy background with neon cyan, purple, and pink accents.
- **Anti-Gravity Cards**: Floating animations and 3D tilt effects on hover.
- **Glassmorphism**: Frosted glass effects for project cards and contact sections.
- **Interactive**: Parallax background globes, glitch text effect, and smooth scrolling.
- **Responsive**: Fully optimized for desktop, tablet, and mobile devices.

## How to Run
Simply open `index.html` in any modern web browser. No server or installation required.

## Tech Stack
- HTML5
- CSS3 (Variables, Flexbox, Grid, Animations)
- Vanilla JavaScript (IntersectionObserver, Event Listeners)
- Google Fonts (Space Mono)
- Font Awesome (Icons)
